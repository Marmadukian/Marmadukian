# Hey, I'm Tim.

I build lean, high-utility tools for games and live streaming. I also like to do gamejams. 

---

### Craftsmanship & Architecture

* **Rapid Prototyping Is Key:** If I can't get the first thing on screen, in a reasonable time-frame, the tool is too complex for me to build on my own. 
* **Fail Gracefully, Fail Invisibly:** If bad, unmapped, or unexpected data hits the pipeline, the tool shouldn't crash your workspace or drop a stream overlay. It fails gracefully and invisibly. It goes invisible. Rather than bad data, it's no data.

---

### Engineering Standards

Modern development tools are the same as when the buzz saw was invented. It speeds things up, but the architecture still needs to stand on its own.

* **If I don't understand, I don't commit:** I at least understand what the code does that I commit. That doesn't prevent me from missing dynamically typed bugs, but the intent is always mine.
* **It Plumbs, I Imagine:** Machine assistance handles syntax translation, repetitive boilerplate, and math verifications. Creative direction, UX feel, and speaking to the public remain entirely human.
