# Hey, I'm Tim.

I build lean, high-utility tools for games and live streaming. I also like to do gamejams. 

---

### Craftsmanship & Architecture

* **Rapid Prototyping Is Key:** If I can't get the first thing on screen, in a reasonable time-frame, the design is bloated. I build functional skeletons first, prove the feedback loop, and iterate under live constraints. 
* **Fail Gracefully, Fail Invisibly:** Tools should not fail and completely crash, if there is an error, it should fail gracefully so your whole production doesn't go down. 

---

### Engineering Standards

Modern development tools are the same as when the buzz saw was invented. It speeds things up, but the architecture still needs to stand on its own.

* **Authoritative Games:** My games are the source of truth when integrated with Twitch. This allows the game state to be the source of truth and handle rate limiting users based on what they ACTUALLY do in the game. 
* **Human based designs:** Machine assistance handles syntax boilerplate, repetitive translation, and arithmetic verification. System design, thread boundaries, and creative direction remain strictly human.
